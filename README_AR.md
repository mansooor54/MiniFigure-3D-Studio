# استوديو MiniFigure ثلاثي الأبعاد

**MiniFigure 3D Studio** هو تطبيق مكتبي مخطّط لنظام Windows لتحويل الصور المصرّح باستخدامها لشخص حقيقي إلى مجسّم صغير ثلاثي الأبعاد يمكن مراجعته ومعالجته بواسطة Blender وتجهيزه للطباعة ثلاثية الأبعاد.

## الحالة الحالية

المشروع في مرحلة **تنفيذ أساسيات المرحلة الثانية**. تمت الموافقة على المعمارية وخطة التنفيذ، لكن التطبيق غير جاهز للتشغيل بعد، ولا تتضمن المستودع حالياً أي محرك ذكاء اصطناعي أو أوزان نماذج أو نسخة Blender أو مُثبّت Windows أو مزوّد خارجي.

سيطبّق الحد الأدنى للمنتج في المرحلة الثانية مسار Fast AI محلياً بصورة افتراضية، مع حفظ المشاريع واستعادتها، والتحقق من الصور، وإزالة الخلفية وتصحيح القناع، وربط محرك توليد واحد مسموح باستخدامه قانونياً، وعارض ثلاثي الأبعاد يعمل دون إنترنت، ومعالجة Blender، وفحوص طباعة أساسية، وتصدير STL وGLB بعد إعادة فتح الملفات والتحقق منها. أما Accurate Scan، والألوان القابلة للطباعة و3MF، والأنماط المتقدمة، والتعريب الكامل، والمُثبّت الإنتاجي فتبقى للمرحلة الثالثة.

## مبادئ هندسية

تستهدف الواجهة المكتبية Python 3.11 وPySide6. تعمل محركات الذكاء الاصطناعي الثقيلة وBlender خارج عملية الواجهة من خلال طلبات ذات إصدار محدد ونتائج يتم التحقق منها. تبقى الصور الأصلية والنماذج الخام عناصر غير قابلة للاستبدال داخل المشروع. لا تُنفّذ العمليات الطويلة في خيط الواجهة، ولا يُعلن نجاح التصدير قبل إعادة فتح الملف والتحقق منه.

التطبيق محلي بصورة افتراضية. يتطلب إرسال أي صورة إلى خدمة خارجية عرض اسم الخدمة والغرض والبيانات المرسلة والحصول على موافقة صريحة. لا تُحفظ مفاتيح API في الشفرة المصدرية أو ملفات المشروع أو السجلات أو سطر الأوامر.

## سلامة المستودع

يُمنع رفع صور أشخاص حقيقيين، أو مفاتيح API، أو ملفات `.env`، أو أوزان النماذج، أو المحركات المنزلة، أو مشاريع المستخدمين، أو نواتج البناء، أو حزم التشخيص. يجب أن تكون بيانات الاختبار اصطناعية أو ذات حقوق إعادة توزيع موثقة ومدرجة في سجل الأصول.
